# Требования перед началом

Студент должен знать основы Linux terminal, Git, Docker, YAML, HTTP, ports,
environment variables и PostgreSQL.

Установите:

- Git;
- Docker Desktop или Docker Engine;
- `kubectl`;
- kind или Minikube;
- текстовый редактор;
- Helm — только по желанию.

Node.js локально не требуется для container-based workflow. Если студент хочет
запускать Vite без Docker, необходим Node.js `22.12+`.

Проверьте:

```bash
git --version
docker --version
docker compose version
kubectl version --client
kind version  # или: minikube version
```

Cloud account, Terraform, domain и банковская карта не требуются.

# Modifications to the upstream project

This student starter is derived from
`fif911/kubernetes-front-end-backend-example` under Apache License 2.0.

The frontend was migrated to React 19 and Vite 8, request handling and backend
health checks were updated, compatible Python dependencies were refreshed, and
legacy infrastructure, credentials and private keys were removed. Students must
create all container and Kubernetes implementation files themselves.
